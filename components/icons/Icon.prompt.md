Single-glyph SVG icon (Lucide outlines) for every icon slot in the system — never inline your own path data.

```jsx
<Icon name="mic" size={22} color="var(--ink-500)" />
```

Available: mic, navigation, plus, chevronLeft, chevronRight, arrowUpRight, bookmark, maximize, minimize, moon, sun, delete, shift, search, compass, sparkle. Icons are stroke-only — no filled glyphs anywhere in this system.

BT additions: `book`, `headphones`, `users`, `check`, `cloudOff`, `globe`, `languages`, `x`.
