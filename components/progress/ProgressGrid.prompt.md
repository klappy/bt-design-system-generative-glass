Progress across books and chapters as tinted cells, never as a percentage bar alone.

```jsx
<ProgressGrid books={[{book:'Ruth',chapters:['done','done','revise','translate']},{book:'Jonah',chapters:['done','done','done','done']}]}/>
```

Default ladder: understand (sky), translate (peach), revise (lavender), done (mint). Pass `stages` for a process with different names.
